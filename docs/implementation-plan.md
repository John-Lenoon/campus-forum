## 回归中发现并修复

- 清理服务引入事务代理后，视频服务直接读取代理字段导致空值；改为显式依赖注入。
- AVI 的 MJPEG 流被图片检测误收；同时验证实际容器与编码，不信任扩展名。
- Unicode 不换行空格未按全空白处理；按 Unicode 空白／空格类别校验，拒绝 NUL 和不完整代理字符。
- FFmpeg 9 将动画 WebP 单独识别为 webp_anim；作品接受、头像拒绝，未把头像静态限制扩展给作品图片。
- Spring 默认参数错误和未知路由缺少稳定 code；补齐错误映射并回归。
- 首次启动端口已监听但管理员尚未初始化，普通注册可抢占 admin；隔离新库确定性复现 201 后，将初始化移到监听前，回归确认 409 及 ADMIN 登录。
