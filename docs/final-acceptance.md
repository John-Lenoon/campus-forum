## 4. 大文件、媒体与恢复

- 实际 1,073,741,824 字节 MP4 通过 128 个 8 MiB 分片传输、合并和处理；不是只校验声明值。临时生成数据在用例结束后经资源回收释放。
- 真实 1,800 秒 MP4 处理为 READY，HLS 清单及全部片段经 HTTP 完整解码；1,801 秒标 FAILED／VIDEO_DURATION_LIMIT。
- 真实错误内容上传可查询 FAILED，不能绑定投稿。
- RabbitMQ 停机时 complete 提交 PROCESSING 数据库任务，资源没有临时过期倒计时；模拟 25h 后仍可查询，不能投稿。恢复后自动重投、处理为 READY。
- 图片和视频原文件、HLS 清单及片段都使用当前状态鉴权；重审／删除后不能使用旧地址绕过权限。
- 头像替换立即公开、旧地址立即禁止且不可复用；当前有效绑定不被临时资源期限清除。
- 另从配置存储根观察 UUID 目录：退休头像／移除附件在 23h 仍存在，到期后经清理确实删除；失败结果在截止前可查、截止时 410 并物理删除；失败片不延长未完成任务期限，当前头像／有效绑定保持存在且可读。
