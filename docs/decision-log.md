# 需求决策记录

## 记录规则

- 保留决策编号、日期、关联问题和已确认结论。
- 原始输入由后续明确决策补充或调整；对应关系见各条引用。
- 候选方案与未决问题见 [open-questions.md](open-questions.md)。
- 未回答不等于接受默认值。
- 已答复问题不重复提问。

- IMPL-001：Java 21、Spring Boot 3.5.16、Maven、Spring JDBC；本机工具已就绪，Boot 官方兼容 Java 21，显式 SQL 便于核验审核事务。

- IMPL-006：页码从 1 开始，越界／非整数参数返回 400；offset 分页，不承诺热榜快照语义。时间 UTC，接口采用 epoch 毫秒，ID 为 UUID 字符串。
- IMPL-007：驳回原因非空白、最多 1,000 码点；JSON 未知字段拒绝，客户端不可指定角色、作者或帖子状态；系统默认头像作为内置静态资源。
- IMPL-008：测试通过公开 HTTP 边界连接真实 openGauss、Redis；仅替换时间边界用于固定 24 小时过期测试。RabbitMQ 使用真实连接验证，其他阶段用例不计本批通过。
- IMPL-009：openGauss A 模式的 VARCHAR 默认按字节限制，真实边界测试发现合法中文／emoji 失败；昵称、标题、驳回原因改用显式 VARCHAR(n CHAR)，不缩短业务字符上限。早期开发库通过 V002 非破坏迁移修正。
- IMPL-010：Q-021/022/023/024/033 采用已记录推荐值：各列表默认 20、最多 100，根评论与每串回复分别分页；评论默认时间正序且可反向；本人互动和历史倒序并以 ID 稳定打破同时间；批量用户 ID 去重、明确 missingIds、输入最多 100 项。依据是沿用第一批列表约定并限制单次请求规模。
- IMPL-011：RV-03 的无已有关系取消操作成功且无变化；非公开帖可删除本人评论，已删除帖禁止操作。依据是互动幂等及既有本人评论删除权，不增加权限。
- IMPL-012：Q-049/RV-01 热榜固定排序采用服务端 ID 快照，有效 10 分钟；同分按首次发布时间倒序、ID 倒序；失效返回 410 REFRESH_REQUIRED。10 分钟是授权内技术默认值，不是用户逐项确认；每页按原快照位置切片再过滤不可公开条目，避免其他条目因过滤移位而跨页遗漏。
- IMPL-013：帖子以 deleted_at 逻辑删除，所有查询仍禁止读取；后续评论级联仅保留本人历史原文。原已确认规则不要求立即物理抹除，不提供恢复入口。
- IMPL-014：RV-02 采用到期立即阻止访问、默认 60 秒扫描，正常情况下下一轮扫描结束时完成物理回收；失败保留错误并下轮重试。管理员可同步调用同一清理逻辑验证完成，当前有效绑定和 PROCESSING 均排除临时期回收。
- IMPL-015：文件存储为私有 MEDIA_ROOT/资源 UUID，所有文件请求走权限校验，文件名固定白名单；不生成可绕过状态的永久公开直链。依据是 BR-18/20/33 的统一访问边界。
- IMPL-016：FFprobe 检测实际容器、编码及帧数；JPG/PNG/WebP 可作为作品图片，头像须静态；作品的动画 WebP 不套用头像限制。FFmpeg 工具来自其官网链接的 Gyan 构建，下载档校验 SHA-256。

- IMPL-019：业务验收以公开 HTTP 为主；物理回收另观察已配置私有存储根中的 UUID 目录，确认到期前保留、到期后确实删除，而非仅检查 404；不通过直接查业务数据库代替接口断言。完整验收包含实际 1 GiB 传输，常规回归可用标签排除大文件用例。
