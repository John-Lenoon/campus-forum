## 1. 验证环境与结果

- Java 21.0.2、Maven 3.9.8、Spring Boot 3.5.16。
- 真实 openGauss 官方镜像 7.0.0-RC3.B025，JDBC 驱动 org.opengauss:opengauss-jdbc:5.0.0。
- 真实 Redis 7-alpine、RabbitMQ 3-management；均通过本批独立 Compose 服务运行，未改动其他项目容器。
- 通过 HTTP 依赖检查返回的 databaseVersion 验证服务器确为 openGauss；测试未使用 H2 或 PostgreSQL 服务器替代。
- 测试使用 forum_test 独立数据库、随机注册账号；不清空开发数据。
- 最终 `mvn verify`：24 项执行，0 失败，0 错误，0 跳过；测试耗时 27.58 秒。这是测试执行时长，不是性能承诺。
- JAR 打包成功；独立进程完成注册、登录、投稿、待审隐藏、审核通过、访客详情及依赖连通冒烟验证。
- 重启独立进程后，帖子及原 Redis 登录凭证仍可用。
- 单独停止本项目 Redis／RabbitMQ：依赖操作明确返回 503，匿名读取已发布详情继续可用；服务恢复后依赖检查恢复 200。
- 三个基础服务最终均 healthy。冒烟 Java 进程在验证后关闭，可按 README 启动正式本地进程。
